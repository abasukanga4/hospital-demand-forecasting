What the uncertainty bands do—and do not—mean

The selected model’s absolute daily-rate errors from 12 calibration origins define a nominal 90% band, using the finite-sample rank ceil((n+1) × 0.90). With 12 examples this uses the largest error. Width is then scaled by each target month’s days. Coverage and width must be read together: conservative bands can cover every observation while remaining too wide to be useful.

These dependent, changing time-series errors do not satisfy an exchangeability guarantee. The empirical coverage here is not a promise about future months. Bands remain frozen throughout the test.

Data vintage, timing and limits

This is a retrospective rolling-origin experiment on one revised publication vintage. An origin means the last month available to the model, not the calendar date when that month was published. Actual publication delays and revisions are not simulated. No patient records are used; national results cannot establish the staffing needs of an individual hospital.

The Type 1 activity series includes all providers; it is distinct from the performance series that excluded certain trial trusts during 2019–2023. Source notes also identify Type 3 shortfalls during a cyber-attack; Type 3 is not this target.
